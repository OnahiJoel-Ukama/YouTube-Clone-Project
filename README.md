# YouTube-inspired interface — frontend practice

A static video-platform browsing interface created to practice HTML and CSS layout.

## Features represented in the UI

- Header with logo, search field, and navigation icons
- Topic/category buttons
- Video thumbnails, titles, channels, and metadata
- Multi-section page layout

## View locally

Download or clone the repository, then open `index.html` in a browser.

```bash
git clone https://github.com/OnahiJoel-Ukama/YouTube-Clone-Project.git
cd YouTube-Clone-Project
```

## Technologies

HTML · CSS · JavaScript (currently an empty placeholder file)

## Project scope and known issues

This is a static UI practice project, not a functional YouTube client. Search, filtering, authentication, and video playback are not implemented as application features. Some markup in `index.html` is malformed and some external images may fail to load.

## Next improvements

Validate HTML, repair broken image sources, improve accessibility, and implement interactive search/filtering.
